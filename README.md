## 📚 Technical Index: Concepts Covered

The core of this repository is divided into foundational blocks, each representing a crucial pillar of software engineering:

### 1. Mathematics & Bit Manipulation
* **Asymptotic Notation:** Rigorous analysis of Time and Space complexities ($O$, $\Omega$, $\Theta$).
* **Number Theory:** Optimized primality testing, Sieve of Eratosthenes, and Euclidean algorithms for GCD/LCM.
* **Bitwise Operations:** Low-level bit manipulation, masks, and binary properties utilized to achieve $O(1)$ optimizations.

### 2. Searching & Sorting Algorithms
* **Linear & Binary Search:** Iterative and recursive searching mechanics, including advanced binary search applications (order-agnostic search, infinite arrays, and search-space reduction).
* **Sorting Frameworks:** Implementation and analysis of:
  * *Iterative/Basic:* Bubble Sort, Selection Sort, and Insertion Sort.
  * *Index-Based:* Cyclic Sort (crucial for pattern-matching missing/duplicated elements).
  * *Divide & Conquer:* Merge Sort and Quick Sort (leveraging pivot-based partitioning).

### 3. Recursion & Backtracking
* **Recursion Mechanics:** Understanding the call stack, memory management, stack frames, and recurrence relations.
* **Divide & Conquer:** Breaking complex problems down into identical sub-problems.
* **Backtracking:** State-space tree exploration, path-finding (Mazes/Matrices), and classic combinatorial puzzles (N-Queens, Sudoku Solver).

### 4. Linear Data Structures
* **Arrays & Dynamic Lists:** Static vs. dynamic memory allocation, resizing mechanics, and multi-dimensional matrix operations.
* **Linked Lists:** Custom implementation of Singly, Doubly, and Circular Linked Lists, focusing on pointer manipulation, cycle detection (Floyd's Algorithm), and reversal techniques.
* **Stacks & Queues:** LIFO and FIFO implementations using both arrays and linked structures. Designing custom variations like Circular Queues, Deques, and Min-Stacks.

### 5. Non-Linear Data Structures
* **Trees & Binary Search Trees (BST):** Properties of hierarchical structures, tree traversals (Pre-order, In-order, Post-order, Level-order), and self-balancing tree concepts.
* **Heaps & Priority Queues:** Min-Heap and Max-Heap implementations, tree representation in arrays, and the HeapSort algorithm.
* **Graphs:** Adjacency matrix and list representations. Core graph traversals (Breadth-First Search and Depth-First Search) alongside connectivity and shortest-path logic.

### 6. Associative Data Structures & Hashing
* **Custom HashMaps:** Internal architecture of hashing, designing effective hash functions, and implementing collision resolution strategies (Chaining via LinkedLists and Open Addressing).
